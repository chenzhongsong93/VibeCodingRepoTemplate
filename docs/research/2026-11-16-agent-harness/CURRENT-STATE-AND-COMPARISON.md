## 1. 判断

模板已经是一个可组合的工程生成器，具有多语言栈、规则、平台薄入口、T0–T3、续接、流程技能、机器检查和 golden 资产。AWB 的主要可借鉴价值是将这些环节连成“任务→验证→基线回刷→交接”的闭环，以及域规格和短交接的持续维护方式；不是把模板改造成 Java 算子服务，也不是再叠一层流程名词。

此次大改版最需要解决三类已见问题：**多个入口各说一套流程；装配选项与门禁依赖脱节；结构检查被赋予超出其实际能力的完成含义。** 建议保留现有投资，先统一权威、配置与验证语义，再引入适合通用项目的域规格。具体设计见 [REDESIGN-PROPOSAL.md](REDESIGN-PROPOSAL.md)。

## 4. 模板已证实的断点与未验证项

| 编号 | 结论与性质 | 影响与最小后续动作 | 证据 |
|---|---|---|---|
| F01 | **事实**：README称19场景，当前目录21；根CLAUDE/assemble/检查脚本路径有失效引用 | 更新入口必须从真实路径和动态资产生成；21不是测试数或全组合数 | T01、T03、P01 |
| F02 | **事实**：非Claude无docs/skills指针；conductor/规则/dev-flow生命周期不统一 | 建立一个规范生命周期和共同发现链；不是再增加一个编排器 | T04–06、P07 |
| F03 | **事实**：未选产品仍要求其文档；非法stage通过；空节不检查 | 门禁按装配清单取必填文档，校验输入；用反例验收而不是只看文件存在 | T08、P02–04 |
| F04 | **事实**：无栈policy生成调用不存在的make目标；英文路径检查不适配中文 | 配置求解和路径映射须同时约束文档、hook、脚本 | T03、T09–11、P05、P11 |
| F05 | **事实**：Node双栈、deployment+编程栈是文档禁用组合，但装配器未拒绝且覆盖文件 | 先拒绝不支持组合；是否支持混合部署或前后端monorepo另行设计，不能把拒绝当实现完整支持 | T02–03、P06、P12 |
| F06 | **事实**：ID脚本不能证明1:1，Java/L3遗漏；未被常规验证入口调用 | 校验多重性及真实测试位置，完整接入门禁；在覆盖之前不能宣称全栈追溯 | T09、P08–10 |
| F07 | **静态事实**：部署检查尾随`|| true`可吞错；Go lint失败可进入降级；release缺真实E2E动作 | 把工具缺失与检查失败分开，必需检查缺工具应blocked；E2E未配置不能声称已验证 | T10 |
| F08 | **静态事实**：cleanup脚本可先强制移除worktree，且有本地/远端删分支路径 | 后续应重新设计为先只读检查和预览、明确授权后执行；本轮没有运行或清理 | T13 |
| F09 | **事实**：规则有“按代码回刷”与“目标偏差须裁决”冲突；commit后才同步SSOT | 正式基线更新应在验收前，先确认是否批准改目标；验收与Git动作分开 | T04、T06–07 |
| F10 | **未知**：各Agent实际加载、Git Bash/macOS行为、栈工具参数兼容、完整测试是否通过 | 后续实施时在声明环境验证并记录版本；本轮不补造“全绿” | T10、T12、T14 |

现有 golden 是需要保留的回归资产。但树/字符串/链接检查和少量内容快照不等于完整运行验证；例如现有一致性测试主要覆盖空ID集合通过，不能反证P08–10。当前完整测试还有临时git提交步骤，本轮遵守“不提交”没有执行（T14）。

## 6. 通用、业务、平台与依赖的边界

- **通用机制**：入口分层、授权与风险、可测试验收、规则唯一归属、稳定域规格、决策沿革、基线回刷、短交接、检查器自证和机器可复现证据。
- **AWB业务**：算子本体/来源/画像、11社区仓、采集与profiling SQL/API、Flyway/H2/PG、DTO字段、业务文档与数据；均不进入通用模板。
- **平台适配**：Claude导入/权限/skill入口、OS路径/行尾/解释器发现、本地hook入口；从公共政策薄适配，不扩充授权。
- **外部依赖**：源仓speckit命令未跟踪，superpowers/codegraph/AgentCenter/codecheck/CloudBuild不是仓内实现；不将其设成核心运行前提。已有本地gitleaks/栈lint/文档工具须区分“本地工具”与“外部扫描服务”，不新增服务或登录依赖。

**调查交付与实施边界**：本轮只新增研究报告/证据/进度；源码、模板、配置、测试和既有文档未改。收纳候选不是已完成迁移，未来实施须依据获准方案推进。
