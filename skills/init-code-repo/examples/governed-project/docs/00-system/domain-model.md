# 作业共享数据与契约

本文件唯一负责字段与公共状态；提交/执行域引用，不各自复制。

## 记录

ID是调用方提供的非空键；payload是不透明输入；state取queued/running/done/failed；成功后的result或失败后的error由执行域写入。Map以ID为键，不能有两个身份相同的记录。

## 公共状态

queued→running→done或failed。开始前先校验状态，终态不可重新进入running。后续若增加取消字段/状态，两个域须共同对照本契约与系统不变量。
